# CP3406 Assessment 1 Submission Checklist

Before uploading, complete these steps:

- Open the project in Android Studio and run it on an emulator or device.
- Confirm the utility screen loads weather data and the Refresh button works.
- Confirm the settings screen updates the city, unit, and detail display.
- Replace all placeholders in `AI_Declaration.md`.
- Create a GitHub repository and commit the project regularly.
- Add your GitHub repository link to the final LearnJCU submission.
- Export the Android project as a zip from Android Studio if required by the dropbox.
- Submit the reflection PDF and AI declaration if applicable.
